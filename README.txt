PJT 진행현황 모바일 웹앱 v3 수정본

대시보드의 모든 진행 단계는 '문서작성 > 제본 입고' 날짜가 없는 현재 진행 중 현장 안에서 집계합니다.

1. 전체 진행 중 = 제본 입고일 없음
2. 점검대상 = 전체 진행 중 중 현장점검 종료일 없음
3. 점검 진행 중 = 전체 진행 중 중 현장점검 계획일 있음 + 현장점검 종료일 없음
4. 점검 완료 = 점검대상 - 점검 진행 중
5. 보고서 미작성 = 전체 진행 중 중 보고서 작성 완료일 없음
6. 보고서 완료 = 전체 진행 중 - 보고서 미작성

검색 결과의 '표시 항목'에서 엑셀 62개 항목 중 원하는 항목만 선택할 수 있습니다.
선택값은 브라우저에 저장되어 언제든 다시 변경할 수 있습니다.
